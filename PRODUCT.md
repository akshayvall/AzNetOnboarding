# Azure Networking Academy

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Akshay is a technical TPM learning networking from first principles so he can reason confidently about Azure networking and Azure Front Door. The academy must begin without assumed networking knowledge and retain a path to applied depth.

## Confirmed direction

The October 24 review and "do it for all" approval establish a calm networking field guide: small learning units, diagrams before configuration, objective-aligned practice, reliable resumption, and progressively revealed technical detail across the full academy.

## Capabilities and constraints

- Preserve Your path / AFD request lab / Progress and Learn / Try it / Quick check.
- Keep existing technical references, optional quizzes, Azure labs, progress backups and deep links accessible.
- Preserve stored learner evidence. Reading and local checks do not prove mastery or execution in Azure.
- Static HTML, CSS and JavaScript; self-hosted assets, offline support, no external trackers or required accounts.
- Changes remain local until the user explicitly approves publication. No Azure resources are deployed by this work.

## Product principles

- Teach a concrete request story before abstract classifications or configuration trivia.
- Give each unit one outcome, a visual, guided action, meaningful check and explanation prompt.
- Allow stopping and returning to the exact unfinished unit and step.
- Introduce complexity when useful rather than displaying every available tool.
- Treat suggested study times and learning-outcome targets as hypotheses to test with learners.

## Evidence and open gates

The October 24 critique records observed navigation, responsive, content and diagram problems. Automated browser and model tests support functionality, not retention claims. Physical-touch, full screen-reader and human delayed-recall evaluation remain separate gates.
